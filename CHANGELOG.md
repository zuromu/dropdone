# Changelog

All notable changes are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- Press Control-Option-D to open or close the panel from any app

## [0.3.0]

### Added
- An app icon
- Command-N adds a new item

### Changed
- Clear in History asks for a second click before deleting everything
- New README with a 60fps demo animation and screenshots of the list and History

## [0.2.0]

### Added
- The menu bar icon shows how many items are left to do
- An Open at login switch in the panel

## [0.1.0]

### Added
- Menu bar checklist panel with Liquid Glass rows
- Check and uncheck items
- Double click to rename, empty names remove the item
- Drag to reorder, right click to delete
- Checked items stay for 5 seconds so you can undo, then move to History
- History view with the finish date, restore, and clear
- Panel height follows the list and rows animate
- Automatic saving to a JSON file
- Unit tests for the store
- CI, CodeQL, and release workflows
